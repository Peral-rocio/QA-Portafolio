# QA Portfolio — Rocío Peralta

Portafolio de testing manual con casos de prueba, reportes de bugs y 
evidencias documentadas, realizados durante mi formación como QA Tester 
Manual (CoderHouse) y de forma autodidacta.

## Contenido

- **casos-de-prueba/** — Casos de prueba diseñados y ejecutados sobre 
  distintas aplicaciones y funcionalidades.
- **reportes-de-bugs/** — Reportes de bugs documentados, incluyendo 
  pasos de reproducción, resultado esperado vs. obtenido y severidad.
- **pruebas-de-api/** — Testing de APIs, incluyendo pruebas realizadas 
  sobre PokeAPI utilizando Postman.
- **pruebas-de-rendimiento/** — Pruebas de stress y performance.
- **capturas/** — Evidencias visuales del proceso de testing.
